Hackathon Evaluation Architecture

Deterministic Judging & Submissions

JudgeForge operates entirely offline with zero cloud dependencies. Built for high-integrity hackathons requiring isolated judge evaluations, Z-score normalization, and cryptographic audit records.

  • Self-Hosted & Air-Gapped
    Zero CDNs, zero third-party telemetry, zero external fonts or hosted auth services.
  • Strict Peer Isolation
    Judges evaluate assigned entries independently without viewing peer ratings or intermediate totals.
  • Z-Score Normalization
    Standardizes score distributions to eliminate grading bias between strict and lenient reviewers.
  • Containerized Persistence
    Instant start via docker compose up with pre-seeded fixtures and SQLite backend.
